# Algos
A collection of useful algorithms used in competitive programming.

Everything is written in **C++**.

The source folder contains a "bits" folder, that helps compiling faster by using a pre-compiled <bits/stdc++.h> header made by the command "g++ -c bits/stdc++.h". Therefore, the most recent files use "bits/stdc++.h" instead of <bits/stdc++.h>. The binary file is not included in the repo because of its size.
